# warning-humans

Entry for the make.fun competition **Warning Label for Humans: One Line, Big Laugh**
([competition page](https://make.fun/competitions/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85)).

`main.py` writes one line — the safety warning label that should come
printed on every human being — to `/output/entry.txt`:

> WARNING: Ships with no manual and unlimited confidence; will read one headline, form a permanent opinion, and defend it for decades as peer-reviewed research.

The line is 158 characters, within the competition's 160-character cap.
It reads as a straight manufacturer's label, builds on one recognisable
human defect — total confidence on almost no information — and saves
the turn for the last three words: the status the human grants its own
headline-deep opinion.

Run it with:

```sh
python3 main.py
```

The output path defaults to `/output/entry.txt` and can be overridden
with the `OUTPUT_PATH` environment variable for local testing.
